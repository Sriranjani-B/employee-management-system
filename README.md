# Employee Management System

A simple CRUD-based web application developed using HTML, CSS, and JavaScript.

## Features

* Add new employees
* View employee records
* Update employee details
* Delete employee records
* Search employees
* Form validation
* Local Storage for data persistence
* Responsive and simple user interface

## Employee Details

The system manages:

* Employee Name
* Email
* Phone Number
* Department
* Designation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## CRUD Operations

* **Create:** Add a new employee
* **Read:** View employee records
* **Update:** Edit employee information
* **Delete:** Remove employee records

## Project Structure

```text
Employee-Management/
└── index.html
```

## How to Run

1. Download or clone the project.
2. Open the `index.html` file.
3. Run it using any modern web browser.
4. Add, edit, search, or delete employee records.

## Data Storage

Employee information is stored in the browser using Local Storage.
